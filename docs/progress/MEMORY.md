# Project Memory (keep this under ~40 lines: facts and decisions only)

## Decisions
- **Stack switch (2026-11-17), see `docs/project-documentation/tech-stack.md`:** admin = Vite SPA + TanStack Router file routes. client = TanStack Start (SSR landing at `/` + `/bn`, logged-in app rendered in the browser). Auth = Better Auth (replaces custom JWT; `organization` plugin = workspaces, `admin` plugin = super admin, Redis `secondaryStorage`). ORM = Drizzle (replaces Prisma, decided 2026-11-17). DB = Neon in prod (pooled `DATABASE_URL`, direct `DIRECT_URL` for migrate), Docker Postgres locally. Redis Cloud free in prod (`noeviction`). Not Next.js, not Supabase. Rework rows: TASKS.md Module 0b.
- Same-origin API: each app calls `/api/*` on its own origin, proxied to the backend, so session cookies are host-only per app (admin stays logged in while impersonating). Dev URLs: `admin.localhost:5173`, `app.localhost:5174`.
- Three independent npm projects (`backend/`, `admin/`, `client/`), no npm workspaces. Docker: one **root `docker-compose.yml`** starts everything (`docker compose up --build`); each project has its own multi-stage Dockerfile (Module 0's `backend/docker-compose.yml` moved to the root).
- The `migrate` compose service runs the backend **runtime** image with `node dist/db/migrate.js` (Drizzle `migrate()` on `backend/drizzle/`) before `backend` starts. Journal table: `drizzle.__drizzle_migrations`. Migrations use `DIRECT_URL` ‖ `DATABASE_URL` (`migrationDatabaseUrl()`; drizzle.config inline); runtime only `DATABASE_URL`. Scripts: `db:generate` / `db:migrate` (drizzle-kit, local) · `db:deploy` (built migrator).
- Health returns 503 (not 200) when any dependency is down. The body always has `database`, `redis` and `latencyMs`. `GET /api/health/live` is DB-free (Docker HEALTHCHECK + uptime monitors use it); both health routes are skipped by pino auto-logging (`isHealthProbe`).
- Admin UI: shadcn `radix-nova` preset (Radix base), Animate UI via `npx @animate-ui/cli@latest animate all` (rewrites installed shadcn components to `@animate-ui/react` primitives; run it again after every `shadcn add`). Buttons/badges/inputs edited to `rounded-full`. `shadcn add` prompts before overwriting existing files: run it as `yes n | npx shadcn add …`. Local edits (M2-T2): `sidebar.tsx` writes no `sidebar_state` cookie, floating panel = `bg-card rounded-2xl ring-border`; `hooks/use-mobile.ts` uses `useSyncExternalStore`. Fonts: Plus Jakarta Sans + Noto Sans Bengali (fontsource variable, `font-bangla` utility).
- Admin wiring: providers live in `src/providers/app-providers.tsx`. `createQueryClient()` defaults: staleTime 30s, retry 1, no refetch on focus. UI store persists to localStorage key `shield-admin-ui`; `.dark` on <html> follows it.
- Frontend Docker: runtime is `nginxinc/nginx-unprivileged` (non-root, listens on the app port). Admin has **no build args**: `nginx.conf.template` (envsubst by the image entrypoint) proxies `/api/` to `API_UPSTREAM` (default `http://backend:3000`, resolver `NGINX_RESOLVER` 127.0.0.11) and sets X-Forwarded-For/Host/Proto; Host stays the upstream's. Vite dev/preview proxy `/api` → `API_PROXY_TARGET` (default `localhost:3000`, `xfwd`).
- Admin routing (SW-T6): `src/router.tsx` `createAppRouter(queryClient, history?)`, context `{ queryClient }`. `_authed` pathless layout guards super admin via `ensureQueryData(sessionQueryOptions)` (`src/lib/session.ts`, key `['auth','session']`) and passes `session` in route context. Routes live under `/admin/*` (no router basepath). `routeTree.gen.ts` is committed + lint-ignored; `-`-prefixed files in `src/routes/` are ignored by the generator (tests). After sign-in/out: clear the session query (login uses `resetQueries`, which dedupes with the guard's fetch; the shell uses `queryClient.clear()`), then `router.invalidate()` / navigate. **M2-T1:** `adminAccess(session)` (`src/lib/session.ts`) = `granted | signed-out | not-super-admin | banned | impersonated`; `_authed` admits only `granted` and fails closed to login if get-session errors; login shows the refusal notice + sign-out. Sign-in errors map via `src/lib/auth-errors.ts` (401, 429 + `X-Retry-After`, 403 `BANNED_USER`, other 403, 400, 5xx, thrown = network). Admin tests: Vitest 5 + jsdom (`npm test`); component tests render `RouterProvider` with memory history (`src/routes/admin/-login.test.tsx`). **Shell (M2-T2):** `src/components/app-shell/` (`nav-items.ts` A2–A7 + `activeNavItem`, `app-sidebar.tsx` floating/icon-collapsible, `user-menu.tsx` = theme radio + sign-out); `SidebarProvider` is controlled by the store's `sidebarCollapsed`, <768 px = off-canvas Sheet; `SidebarInset` is the `<main>`. Screens start from `PageHeader`/`PlaceholderPage` (`src/components/placeholder-page.tsx`). jsdom tests that open Animate UI menus need stubs for `matchMedia`, `Element.prototype.animate`/`getAnimations` and `SVGGeometryElement` (see `src/routes/-shell.test.tsx`). Vitest gotchas: a function returned from `beforeEach` runs as teardown (`() => mock.mockReset()` calls the mock), and `setDefaultOptions` replaces all query defaults (spread `getDefaultOptions()`).
- Backend `TRUSTED_ORIGINS`/`CORS_ORIGINS` defaults list `http://admin.localhost:5173,http://app.localhost:5174` (+ plain localhost). Better Auth rejects other Origins with 403.

- Client (SW-T7) = **TanStack Start** 1.169 (Vite 8, `tanstackStart()` before `react()`; autoCodeSplitting on by default). `src/router.tsx` `getRouter()` makes a per-request QueryClient + language store, context `{ queryClient, languageStore }`, `setupRouterSsrQueryIntegration` (it provides QueryClientProvider). `components/ui` + `globals.css` stay in sync with admin: a new shadcn component goes through `shadcn add` + `animate all` in each app. Tests: `vitest.config.ts` (no Start plugin), jsdom.

- DB conventions: use `id()`, `timestamptz()`, `timestamps` from `src/db/schema/columns.ts` (UUIDv7 via `uuidv7`, `timestamptz(3)`, `updatedAt` `$onUpdate`). camelCase TS → snake_case SQL via `casing: 'snake_case'` (db.module + drizzle.config). - Authz (M1-T1, `src/auth/guards/`): `WorkspaceAccessGuard` on `:workspaceId` routes (404 non-member/unknown/malformed, 403 suspended or role not in `@Roles`, impersonated session locked to `activeOrganizationId`; sets `request.workspace`, read via `@CurrentWorkspace()`). Our `@Roles('owner','admin')` = workspace roles (key `workspace:roles`; the lib's `@Roles` is platform `user.role`, don't mix). `RolesGuard` = same check on the session's active workspace. `SuperAdminGuard` re-reads `users.role/banned` from Postgres and rejects `impersonatedBy`. Session type `AuthSession` (`src/auth/auth-session.ts`); membership queries in `src/auth/authz-queries.ts`.
- **Impersonation (M1-T3, user decisions 2026-11-18):** `POST /api/admin/clients/:workspaceId/impersonate` (SuperAdminGuard, 200 `{ token, redirectUrl }`, `CLIENT_APP_URL` + `/impersonate?token=`) → `POST /api/auth/impersonate-exchange` `{ token }` (plugin `src/auth/impersonation-exchange.plugin.ts`; 400 bad shape, 401 unknown/expired/used, 403 admin no longer super admin, 404/409 re-checked). Token 32 B base64url, 60 s, sha256 in `impersonation_audit_logs` (FKs `restrict`: e2e `cleanup()` deletes audit rows first), burned by one guarded UPDATE. Decisions: (1) session = exactly 1 h, never extended (`session.update.before` keeps `expiresAt` when `ctx.context.session` is impersonated; + dont_remember cookie); (2) SUSPENDED → 409, no token/audit row; (3) oldest `owner` membership (`created_at`, `id`), skipping banned (expired `banExpires` = not banned), none → 409; (4) Better Auth `admin/impersonate-user` + `admin/stop-impersonating` are `disabledPaths` (404). Impersonated sessions get 403 on `/api/auth/admin/*`, `organization/set-active`, `organization/create` and (**user decision, M1-GATE**) the owner's account routes `IMPERSONATION_BLOCKED_ACCOUNT_PATHS` (change-password/email, update/delete-user, revoke-session(s), link/unlink, verify/set-password, access/refresh-token), all via `isBlockedWhileImpersonating` in `src/auth/better-auth.ts` (extend that list; no second mechanism). `get-session` + `sign-out` stay open.
